# TrendVault - Viral Product Showcase & Affiliate Store

A fast, mobile-responsive product showcase landing page built with HTML, Tailwind CSS, and Vanilla JavaScript.

## Features
- Category filtering (Winter Gadgets, Plushies, Smart Pet Toys, Desk & Car Gear)
- Live urgency countdown timer
- Easy product management via `script.js`
- Ready for GitHub Pages, Vercel, or Netlify deployment
